# Nexo — Rede Social de Projetos

Uma rede social inovadora que combina a experiência familiar do Facebook e Instagram com colaboração prática. Na Nexo, publicações podem se transformar em projetos, missões e oportunidades para construir algo em equipe.

## Demonstração

https://nexo-rede-social-abner.phpjs5457.chatgpt.site

## Diferenciais

- Feed social focado em ideias e resultados reais
- Stories para compartilhar evolução e bastidores
- Publicações rápidas diretamente no feed
- Projetos com progresso público e colaboradores
- Filtros por impacto, tecnologia e comunidade
- Curtidas, itens salvos e participação em projetos
- Missões semanais para tirar ideias do papel
- Interface responsiva para computador e celular

## Tecnologias

- React 19
- TypeScript
- Next.js 16
- Vinext e Vite
- Tailwind CSS 4

## Executar localmente

```bash
npm install
npm run dev
```

Depois, acesse o endereço exibido no terminal.
